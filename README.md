## 📖 About

**KeyCraft** is a modern e-commerce platform built for selling premium-quality custom keychains. Customers can browse products, personalize designs, securely place orders, and track purchases through an intuitive and responsive interface.

The platform combines a clean UI with powerful backend features to deliver a seamless shopping experience across desktop, tablet, and mobile devices.
